# DERICK — Personal Website

A responsive personal website for Asiimwe Derick, presenting his professional identity, ventures, selected projects, areas of interest and long-term Vision 2040.

## Built with
- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts (DM Sans and Space Grotesk)

## Run locally
Open `index.html` in a browser. No build step or package installation is required.

## Deploy to GitHub Pages
1. Open the repository: https://github.com/asiimwe3/derick-personal-website
2. Select **Add file → Upload files**.
3. Extract this ZIP on your device and upload the contents of this folder (not the ZIP itself).
4. Commit the files to the `main` branch.
5. Open **Settings → Pages**.
6. Under Build and deployment, choose **Deploy from a branch**.
7. Select `main` and `/ (root)`, then save.

The site should become available at:
https://asiimwe3.github.io/derick-personal-website/

## Before public launch
- Review the biography and confirm all wording is accurate.
- Confirm project statuses and public links.
- Add a professional portrait and verified social links if desired.
- Configure a custom domain and analytics if required.
