# Asiimwe Derick, personal website

A personal website: who I am, what I'm learning and what I'm making.

Live: https://asiimwe3.github.io/derick-personal-website/

## Built with
HTML, CSS and vanilla JavaScript. No build step. Open `index.html` to run it locally.

## Structure
- `index.html`: the page (Me, My days, What I build, Photos, Notes, Hello)
- `styles.css`: styling
- `assets/`: photos, optimised to WebP
- `dcp.js`: privacy-friendly first-party visit counter (no cookies, no personal data)
